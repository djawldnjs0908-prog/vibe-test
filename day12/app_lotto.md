# PRD: 로또 번호 생성기 (app_lotto)

## 1. 개요

| 항목 | 내용 |
|---|---|
| 제품명 | 로또 번호 생성기 |
| 목적 | 사용자가 고정수/제외수를 지정하고, 버튼 한 번으로 로또 번호 5세트를 생성·기록·복사할 수 있는 웹 앱 |
| 대상 | 로또를 구매하기 전 번호를 뽑아보고 싶은 일반 사용자 |
| 플랫폼 | 웹 브라우저 (PC / 모바일 반응형) |
| 기술 | HTML, CSS, JavaScript (순수 Vanilla JS, 빌드 도구 없음) |
| 디자인 | Bootstrap 5 (CDN) + Bootstrap Icons (CDN) |
| 서버 | 없음. 정적 파일만으로 동작 (`index.html` 더블클릭으로 실행 가능해야 함) |

### 범위에서 제외 (Out of scope)
- 지난 회차 당첨번호 조회 (외부 API CORS 문제로 제외)
- 6개 번호를 모두 직접 고르는 완전 수동 세트
- 회원가입, 서버 저장, 당첨 확인 기능

## 2. 파일 구조

파일은 반드시 HTML / CSS / JS 로 분리한다.

```
day12/
├── index.html        # 마크업 + Bootstrap CDN 로드
├── css/
│   └── style.css     # 커스텀 스타일 (로또 공 색상, 선택판 등)
└── js/
    └── app.js        # 모든 동작 로직
```

- `index.html` 에는 인라인 `<style>`, 인라인 `<script>`, 인라인 이벤트 속성(`onclick=`)을 쓰지 않는다.
- `app.js` 는 `<body>` 끝에서 `defer` 없이 로드하거나, `<head>` 에서 `defer` 로 로드한다.

### CDN
```html
<link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
<link href="https://cdn.jsdelivr.net/npm/bootstrap-icons@1.11.3/font/bootstrap-icons.min.css" rel="stylesheet">
<script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
```

## 4. 기능 요구사항

### F1. 고정수 선택 (②)
- 1~45 번호 버튼을 그리드로 표시한다 (한 줄 7~9개, 원형 버튼).
- 버튼을 클릭하면 선택/해제가 토글된다.
- **최대 5개**까지 선택 가능. 6번째 선택 시도 시 선택되지 않고 안내 메시지(토스트 또는 패널 하단 텍스트)를 표시한다.
  - 문구: `고정수는 최대 5개까지 고를 수 있어요.`
- 선택된 버튼은 파란 계열(`btn-primary` 계열)로 강조한다.
- 헤더에 `고정 N/5` 카운터를 표시한다.
- `초기화` 버튼으로 고정수만 전부 해제한다.

### F2. 제외수 선택 (③)
- F1과 동일한 1~45 그리드.
- 선택된 버튼은 빨간 계열(`btn-danger` 계열)로 강조한다.
- **최대 39개**까지 선택 가능 (생성 가능한 번호가 최소 6개 남도록). 초과 시 안내:
  - 문구: `제외수는 최대 39개까지 고를 수 있어요.`
- 헤더에 `제외 N/39` 카운터, `초기화` 버튼.

### F3. 고정수 ↔ 제외수 상호 배타
- 고정수로 선택된 번호는 제외수 판에서 **비활성화**(점선 테두리, 흐린 글자, 클릭 불가) 처리한다.
- 반대로 제외수로 선택된 번호는 고정수 판에서 비활성화한다.
- 비활성화된 버튼에는 `disabled` 속성과 `title="고정수로 선택됨"` / `title="제외수로 선택됨"` 을 준다.

### F4. 번호 생성 (④)
- `번호 생성 (5세트)` 버튼을 누르면 5세트(A~E)를 생성한다.
- 각 세트 생성 규칙:
  1. 고정수를 모두 포함한다.
  2. 후보 풀 = 1~45 중 (고정수 ∪ 제외수)를 뺀 나머지.
  3. 후보 풀에서 `6 - 고정수 개수` 만큼 **중복 없이** 무작위 추출한다.
  4. 6개 번호를 오름차순 정렬한다.
- 세트끼리는 독립적으로 생성한다 (세트 간 중복 허용).
- 유형 표시: 고정수가 0개면 `자동`, 1개 이상이면 `반자동`.
- 난수는 `crypto.getRandomValues()` 를 사용한다 (미지원 시 `Math.random()` 폴백).
- 생성 즉시 ⑤ 결과 영역을 갱신하고, F6 기록에 추가한다.

### F5. 생성 결과 표시 (⑤)
- A~E 5줄로 표시. 각 줄: `라벨 | 공 6개 | 유형 배지 | 복사 버튼`.
- 공은 원형이며 번호대별 색상 (실제 로또 공 규칙):

| 번호대 | 색상 | 예시 HEX |
|---|---|---|
| 1–10 | 노랑 | `#FBC400` |
| 11–20 | 파랑 | `#69C8F2` |
| 21–30 | 빨강 | `#FF7272` |
| 31–40 | 회색 | `#AAAAAA` |
| 41–45 | 초록 | `#B0D840` |

- 고정수에 해당하는 공은 외곽선(outline)으로 추가 강조한다.
- 생성 전 초기 상태 문구: `번호 생성 버튼을 눌러보세요.`
- 생성 시 공이 짧게 나타나는 애니메이션(fade/scale, 0.3초 이내)을 준다. (선택 사항)

### F6. 생성 기록 (⑥)
- 생성할 때마다 아래 정보를 한 건으로 저장한다.
- 목록은 **최근순** 정렬, 각 건은 Bootstrap Accordion 또는 `<details>` 로 접기/펼치기. 가장 최근 건만 기본 펼침.
- 각 건 헤더: `MM/DD HH:mm · 고정 N · 제외 M` + `복사` 버튼 + `삭제(X)` 버튼.
- 펼치면 5세트 공을 작은 크기로 표시 (고정수 외곽선 강조 유지).
- `전체 삭제` 버튼: `confirm('생성 기록을 모두 삭제할까요?')` 확인 후 전체 삭제.
- **최대 20건** 보관. 21번째 저장 시 가장 오래된 기록을 삭제.
- 기록이 없을 때 문구: `번호를 생성하면 여기에 기록이 쌓입니다.`
- 헤더에 총 건수 `N건` 표시.

### F7. 저장 (localStorage)
- 생성 기록은 `localStorage` 에 저장하여 새로고침/재방문 시에도 유지한다.
- 키: `lotto.history.v1`
- 고정수/제외수 선택 상태는 저장하지 않는다 (새로고침 시 초기화).
- `localStorage` 읽기/쓰기는 `try/catch` 로 감싸고, 실패해도 앱은 메모리 기록으로 정상 동작해야 한다.
- 저장된 JSON 파싱 실패 시 기록을 빈 배열로 초기화한다.

### F8. 복사
- 복사 버튼 위치 3곳:
  1. ⑤ 각 세트 줄의 `복사` → 해당 1세트
  2. ⑤ 헤더의 `전체 복사` → 이번 결과 5세트
  3. ⑥ 각 기록 헤더의 `복사` → 해당 기록 5세트
- 복사 텍스트 형식:
  ```
  [로또 번호] 2026-10-09 14:00
  A: 03 14 22 31 38 42 (반자동)
  B: 05 11 19 27 33 44 (반자동)
  C: ...
  D: ...
  E: ...
  ```
  - 1세트 복사 시: `A: 03 14 22 31 38 42` 한 줄만.
  - 번호는 2자리 0패딩, 공백 구분.
- `navigator.clipboard.writeText()` 사용. 실패 시(파일 직접 열기 등) 숨김 `<textarea>` + `document.execCommand('copy')` 폴백.
- 복사 성공 시 Bootstrap Toast로 `복사했어요.` 표시 (2초 후 자동 닫힘). 실패 시 `복사하지 못했어요. 다시 시도해 주세요.`

## 6. JS 구성 (app.js)

함수 단위로 나눠 작성한다. 전역 오염을 피하기 위해 모듈 패턴(IIFE) 또는 `DOMContentLoaded` 내부에 둔다.

| 함수 | 역할 |
|---|---|
| `init()` | 그리드 생성, 이벤트 바인딩, 기록 로드 후 렌더 |
| `renderPicker(type)` | 고정/제외 그리드 버튼 상태 갱신 (선택·비활성) |
| `toggleNumber(type, n)` | 선택 토글 + 최대 개수/상호 배타 검사 |
| `clearPicker(type)` | 해당 판 초기화 |
| `randomInt(max)` | `crypto.getRandomValues` 기반 0 ~ max-1 정수 |
| `generateSet(fixed, excluded)` | 1세트(6개, 정렬) 생성 |
| `generateAll()` | 5세트 생성 → `state.current` 설정 → 기록 추가 → 렌더 |
| `renderResult()` | ⑤ 영역 렌더 |
| `renderHistory()` | ⑥ 영역 렌더 |
| `ballHTML(n, isFixed, size)` | 공 하나의 HTML 문자열 (번호대 색 클래스) |
| `getBallClass(n)` | `ball-yellow` / `ball-blue` / `ball-red` / `ball-gray` / `ball-green` |
| `loadHistory()` / `saveHistory()` | localStorage 읽기/쓰기 (try/catch) |
| `deleteHistory(id)` / `clearHistory()` | 기록 삭제 |
| `formatSets(item)` / `formatSet(label, set)` | 복사용 텍스트 생성 |
| `copyText(text)` | 클립보드 복사 + 폴백 |
| `showToast(message)` | Bootstrap Toast 표시 |

- 동적으로 만든 버튼의 이벤트는 **이벤트 위임**(부모에 `click` 리스너 하나, `data-number` / `data-action` / `data-id` 속성 사용)으로 처리한다.

## 7. 스타일 (style.css)

- `.ball` : 원형(지름 40px, 기록 영역은 28px), 가운데 정렬, 굵은 숫자, 약한 그림자.
- `.ball-yellow` ~ `.ball-green` : F5 표의 색상.
- `.ball.is-fixed` : `outline: 2px solid #0d6efd; outline-offset: 2px;`
- `.num-btn` : 선택판 원형 버튼 (aspect-ratio 1, 폭은 그리드에 맞춤).
- `.num-btn.fixed` (파랑), `.num-btn.excluded` (빨강), `.num-btn:disabled` (점선 테두리, opacity 낮춤).
- 선택판 그리드: `display: grid; grid-template-columns: repeat(9, 1fr); gap: 6px;` (모바일 `repeat(7, 1fr)`)
- 고정수 카드 상단 파란 선, 제외수 카드 상단 빨간 선으로 구분.
- 색은 CSS 변수(`:root`)로 정의한다.

## 9. 수용 기준 (Acceptance Criteria)

- [ ] `index.html` 을 브라우저로 직접 열어 서버 없이 동작한다.
- [ ] HTML / CSS / JS 가 각각 별도 파일이며 인라인 스크립트·스타일이 없다.
- [ ] 고정수는 5개, 제외수는 39개를 초과해 선택할 수 없고 안내 메시지가 뜬다.
- [ ] 한쪽에서 선택한 번호는 반대쪽에서 클릭할 수 없다.
- [ ] 생성 버튼 클릭 시 5세트가 표시되고, 각 세트는 중복 없는 6개 오름차순 번호다.
- [ ] 모든 세트에 고정수가 포함되고, 제외수는 하나도 포함되지 않는다.
- [ ] 고정수 0개면 `자동`, 1개 이상이면 `반자동` 으로 표시된다.
- [ ] 생성할 때마다 기록이 맨 위에 추가되고, 20건 초과 시 가장 오래된 것이 삭제된다.
- [ ] 새로고침 후에도 생성 기록이 유지된다.
- [ ] 기록 개별 삭제 / 전체 삭제(확인창)가 동작한다.
- [ ] 1세트 복사, 전체 복사, 기록 복사가 정해진 텍스트 형식으로 복사되고 토스트가 뜬다.
- [ ] 768px 미만에서 고정수/제외수 판이 위아래로 쌓이고 가로 스크롤이 생기지 않는다.

## 10. 구현 순서 (Claude Code 작업 단계)

1. `index.html` 골격 + Bootstrap CDN + 섹션 ①~⑥ 마크업 + Toast 컨테이너
2. `css/style.css` : 공 색상, 선택판 그리드, 반응형

4. 번호 생성 + 결과 렌더 (F4~F5)
5. 생성 기록 + localStorage (F6~F7)
6. 복사 + 토스트 (F8)
7. 수용 기준 체크리스트로 직접 검증
