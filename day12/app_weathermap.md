# PRD: Weather Map (지도 기반 날씨 앱)

## 1. 개요

| 항목 | 내용 |
|---|---|
| 앱 이름 | Weather Map |
| 목적 | 지도 위 도시 핀을 클릭하여 해당 도시의 현재 날씨, 미세먼지, 5일 예보를 한눈에 확인 |
| 대상 | 대한민국 및 세계 주요 도시의 날씨를 빠르게 확인하고 싶은 사용자 |
| 기술 스택 | HTML5, CSS3, Vanilla JavaScript (ES6+), Bootstrap 5.3, Leaflet 1.9 |
| 데이터 | OpenWeatherMap API |
| 실행 방식 | 빌드 도구 없음. `index.html`을 브라우저(또는 Live Server)로 열어 실행 |

## 2. 핵심 요구사항

1. **대한민국 날씨**와 **세계 날씨**를 탭으로 구분한다.
2. 화면 상단에 **가로 전체를 차지하는 낮은 높이의 지도**를 배치한다.
3. 지도는 **드래그/휠로 자유롭게 이동·확대**할 수 있다 (영역 제한 없음).
4. 지도 위 **도시마다 핀**이 있고, 핀을 클릭하면 해당 도시의 날씨가 카드에 표시된다.
5. 선택한 도시 이름 옆에 **현재 날씨에 맞는 이모티콘**(☀️ ⛅ ☁️ 🌧️ 등)을 표시한다.
6. 표시 정보: 현재 기온, 체감 온도, 날씨 설명, **최고/최저 기온, 풍속, 풍향, 습도, 미세먼지(PM10), 초미세먼지(PM2.5)**, **5일 예보**
7. 정보는 **카드별로 분리**하고, 각 카드는 **서로 다른 연한 색**으로 채운다.
8. 파일은 HTML / CSS / JS로 분리한다.

## 6. 화면 구성

### 6.1 전체 레이아웃 (데스크톱)

```
┌──────────────────────────────────────────────────────────┐
│ ☁ Weather Map                 [대한민국 날씨][세계 날씨]  │  ← 헤더
├──────────────────────────────────────────────────────────┤
│                                                          │
│        지도 (가로 100%, 높이 320px) — 도시 핀            │  ← 지도
│                                                          │
├──────────────┬────────────┬────────────┬─────────────────┤
│              │ 최고/최저  │ 풍속       │ 풍향            │
│ 메인 카드    │ 19° / 11°  │ 4.1 m/s    │ 북동풍 ↙        │
│ 서울 ☀️      ├────────────┼────────────┼─────────────────┤
│ 18°          │ 습도       │ 미세먼지   │ 초미세먼지      │
│ 맑음·체감17° │ 62%        │ 24 ㎍/㎥   │ 21 ㎍/㎥        │
│              │            │ PM10·좋음  │ PM2.5·보통      │
├──────────────┴────────────┴────────────┴─────────────────┤
│ 5일 예보                                                 │
│ [토 ☁️ 19°/11°][일 🌧️ ..][월 ☀️ ..][화 ☀️ ..][수 ☁️ ..]  │
└──────────────────────────────────────────────────────────┘
```

- 최대 너비: Bootstrap `container` (최대 1140px), 가운데 정렬
- 카드 영역: 4열 그리드. 메인 카드는 1열 × 2행(`grid-row: span 2`), 상세 카드 6개는 3열 × 2행
- 5일 예보 카드: 가로 전체, 내부에 5개의 요일 타일
- 모든 요소 사이 간격: 16px (`gap-3`)

### 6.2 헤더

- 왼쪽: 구름 아이콘 + "Weather Map" (굵기 600, 20px)
- 오른쪽: Bootstrap `nav-pills` 형태의 탭 2개 — `대한민국 날씨`(기본 선택), `세계 날씨`
  - 탭 컨테이너는 연회색 둥근 배경(pill), 선택된 탭은 흰 배경 + 진한 글자

### 6.3 지도

| 항목 | 대한민국 탭 | 세계 탭 |
|---|---|---|
| 초기 중심 | `[36.3, 127.8]` | `[20, 10]` |
| 초기 줌 | 7 | 2 |
| 핀 라벨 | 모든 핀에 도시 이름 표시 | 선택된 핀에만 이름 표시 (겹침 방지) |

- 크기: 가로 100%, 높이 **320px** (태블릿 260px, 모바일 220px)
- 모서리 둥글게(16px), 얇은 테두리
- 이동/확대: 제한 없음 (`maxBounds` 미설정). 세계 탭은 `minZoom: 2`, `worldCopyJump: true`
- 탭 전환 시 해당 탭의 핀 레이어로 교체하고 `flyTo`로 초기 위치 이동, 첫 번째 도시(서울)를 자동 선택

#### 핀 디자인

- `L.divIcon`으로 커스텀 핀 제작 (물방울 모양, 지름 약 22px)
- 기본: 흰 배경 + 파란 테두리(`#378ADD`) + 파란 점
- 선택됨: 파란 배경 + 흰 점, 라벨 굵게, **라벨에 날씨 이모티콘 추가** (예: `서울 ☀️`)
- hover 시 살짝 확대(`transform: scale(1.1)`)와 커서 포인터

### 6.4 메인 날씨 카드

- 배경 연하늘 `#E6F1FB`, 글자 `#0C447C`
- 내용
  - 도시명 + 날씨 이모티콘 (24px, 굵게) — 예: `서울 ☀️`
  - 국가/구분 + 현지 날짜·시간 (14px) — 예: `대한민국 · 10월 9일 (금) 14:00`
  - 현재 기온 (56px, 굵게) — 예: `18°`
  - 날씨 설명 + 체감 온도 (16px) — 예: `맑음 · 체감 17°`

## 8. 데이터 가공 규칙

### 8.1 날씨 이모티콘 매핑 (`weather[0].id`, `weather[0].icon` 기준)

| 조건 | 이모티콘 | 설명 |
|---|---|---|
| 200–299 | ⛈️ | 뇌우 |
| 300–399 | 🌦️ | 이슬비 |
| 500–599 | 🌧️ | 비 |
| 600–699 | ❄️ | 눈 |
| 700–799 | 🌫️ | 안개/연무 |
| 800 (낮 `d`) | ☀️ | 맑음 |
| 800 (밤 `n`) | 🌙 | 맑은 밤 |
| 801 | 🌤️ | 구름 조금 |
| 802 | ⛅ | 구름 |
| 803–804 | ☁️ | 흐림 |

### 8.2 풍향 변환 (`wind.deg` → 8방위)

- `index = Math.round(deg / 45) % 8`
- `["북풍 ↓", "북동풍 ↙", "동풍 ←", "남동풍 ↖", "남풍 ↑", "남서풍 ↗", "서풍 →", "북서풍 ↘"]`
- (화살표는 바람이 불어가는 방향)

### 8.3 미세먼지 등급 (환경부 기준, 단위 ㎍/㎥)

| 등급 | PM10 | PM2.5 |
|---|---|---|
| 좋음 | 0–30 | 0–15 |
| 보통 | 31–80 | 16–35 |
| 나쁨 | 81–150 | 36–75 |
| 매우나쁨 | 151 이상 | 76 이상 |

- 값은 정수로 반올림하여 표시한다.

### 8.4 5일 예보 가공

- `forecast.list`(3시간 간격 40개)를 **도시 현지 날짜**(`dt + city.timezone`) 기준으로 그룹화한다.
- 오늘을 제외한 다음 날부터 5일을 표시한다. (데이터가 부족하면 오늘 포함)
- 하루 최고 = 그룹 내 `temp_max`의 최댓값, 최저 = `temp_min`의 최솟값
- 대표 날씨 = 현지 12:00에 가장 가까운 항목의 `weather[0]`
- 요일은 한글 한 글자(`일 월 화 수 목 금 토`)

### 8.5 시간 표시

- 현재 날씨의 `dt + timezone`(초)으로 **도시 현지 시각**을 계산하여 `10월 9일 (금) 14:00` 형식으로 표시한다.
- 기온은 모두 `Math.round()` 후 `°` 표기, 풍속은 소수점 1자리.

## 9. 동작 흐름

1. 페이지 로드 → 지도 초기화(대한민국 탭) → 한국 도시 핀 생성 → 서울 자동 선택
2. 핀 클릭
   1. 이전 선택 핀 스타일 해제, 현재 핀을 선택 스타일로 변경
   2. 카드에 로딩 스켈레톤 표시
   3. 캐시 확인 → 없으면 3개 API 병렬 호출
   4. 메인 카드, 상세 카드 6개, 5일 예보 렌더링
   5. 선택 핀 라벨에 날씨 이모티콘 추가
3. 탭 전환
   1. 탭 활성 상태 변경
   2. 기존 핀 레이어 제거 → 새 탭의 핀 레이어 추가
   3. 지도 `flyTo` 초기 위치
   4. 해당 탭 첫 번째 도시 자동 선택
4. 지도 이동/확대는 자유롭게 가능하며, 탭 전환 전까지 위치를 유지한다.

- 폰트: Pretendard → 시스템 sans-serif
- 카드: 그림자 없음, 테두리 없음, 연한 배경색으로만 구분, 둥근 모서리 16px
- 강조색: 파랑 `#378ADD` (핀, 선택 탭 등 최소한으로만 사용)
- 카드 hover: `transform: translateY(-2px)`, `transition: 0.2s`
- 색상은 `style.css` 상단 `:root`에 CSS 변수로 정의한다. 예: `--card-temp-bg`, `--card-temp-fg`
